# 보라 — 2026 캘린더 & 포커스

2026년 일정을 날짜별로 관리하고, 뽀모도로 집중 시간을 함께 기록할 수 있는 웹 캘린더 앱입니다. 오늘의 할 일과 집중 타이머를 먼저 확인한 뒤, 아래 캘린더에서 날짜별 기록을 이어서 볼 수 있도록 구성했습니다.

배포 URL: [https://bora-focus-2026-lucia.lucyjy1157.chatgpt.site](https://bora-focus-2026-lucia.lucyjy1157.chatgpt.site)

## 주요 기능

- 2026년 월간 캘린더 보기
- 날짜별 할 일 추가, 완료 표시, 삭제
- 상단 닉네임 설정 및 저장
- 뽀모도로 집중 타이머 실행, 일시정지, 초기화, 다음 단계 이동
- 집중 시간, 짧은 휴식, 긴 휴식, 세트 수 직접 설정
- 선택한 날짜, 해당 월, 최근 7일 기준 집중 통계 확인
- 현재 타이머 상태 공유 링크 생성
- 공유 링크에서 집중 중인지, 휴식 중인지, 남은 시간과 종료 예정 시간 확인

## 디자인 기준

- 메인 컬러: 보라색
- 폰트: Pretendard
- 이모지와 그라디언트 미사용
- 데스크톱과 모바일 화면을 모두 고려한 반응형 레이아웃

## 기술 구성

이 프로젝트는 별도 프레임워크 없이 정적 파일만으로 동작합니다.

- `HTML`: 화면 구조
- `CSS`: 레이아웃, 색상, 반응형 스타일
- `JavaScript`: 캘린더 렌더링, 할 일 저장, 타이머, 통계, 공유 링크
- `localStorage`: 닉네임, 할 일, 타이머 설정, 집중 기록 저장

## 파일 구조

```text
.
├── README.md
├── .openai/
│   └── hosting.json
└── dist/
    ├── index.html
    ├── styles.css
    └── app.js
```

## 로컬 실행

정적 파일이라 브라우저에서 `dist/index.html`을 직접 열어도 동작합니다. 로컬 서버로 확인하려면 프로젝트 루트에서 아래 명령을 실행합니다.

```bash
python3 -m http.server 8811 --directory dist
```

그 다음 브라우저에서 아래 주소를 엽니다.

```text
http://127.0.0.1:8811/
```

## 데이터 저장 방식

앱 데이터는 사용자의 브라우저 `localStorage`에 저장됩니다. 서버 계정이나 데이터베이스를 사용하지 않기 때문에, 같은 브라우저에서는 기록이 유지되지만 다른 기기나 다른 브라우저와 자동 동기화되지는 않습니다.

## 배포

배포 설정은 `.openai/hosting.json`에 있습니다. 현재 정적 파일 디렉터리는 `dist`로 설정되어 있습니다.
